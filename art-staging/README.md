# Staged key art — NOT published

Art that has no home yet. Anything in `public/posters/` is served at
`https://www.verzatv.com/posters/<name>.png` whether or not it is committed —
`vercel --prod` uploads the working directory, not the git tree — so unreleased
and wrong-language art lives here instead, outside `public/`, where Next.js
does not serve it.

Move a file into `public/posters/` and commit it only when the title it belongs
to is going live with correct-language art.
